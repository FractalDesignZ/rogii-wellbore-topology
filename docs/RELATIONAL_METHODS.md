# Relational methods and their evidence

At a measured-depth station, a survey coordinate, a gamma-ray reading and a candidate true vertical thickness (TVT) have different roles. The survey and instrument supply observations. The candidate is a hypothesis. A relationship gives a reason to prefer one possible move between depth states. The central question is whether later observations can resolve an earlier ambiguity, and whether the resulting path predicts TVT accurately enough to justify the work spent finding it.

## From source facts to a path

A zero-dimensional starting point has a concrete meaning here. Each source record can supply vertices with identifiable values, units and provenance. Once measured relations connect them, the connected components of that graph describe its zeroth homology. A shared numeric value alone does not establish a measured relation.

## Three views of the same measurements

A matched comparison starts with one role-filtered record of observations, source units and station identities. Each derived value identifies its parents. The following interfaces specify how that same evidence can reach three different predictors.

| Consumer | How it uses a candidate crossing | Existing evidence and remaining comparison |
| --- | --- | --- |
| Relationship graph | Two keyed depth states identify the move. Local observations determine evidence, support and weight on that edge. A decoder returns reachable states or a selected path. | Public hard-search and weighted-path interfaces exist. Exact field coverage and the proportion of ambiguous outcomes depend on the decoder. |
| Conventional estimator | One station or block supplies a row. Named columns summarize candidate costs, separations between alternatives, geometric agreement and missing support. An estimator can learn a continuous depth or rank candidate moves. | The BASE92 implementation preserves the training feature order and training medians for prediction. The separately measured soft Julia comparison used a boosted-tree learner on graph summaries. [Block model](EXPERIMENTAL_BLOCK_MODEL.md) |
| Sequence neural network | The same keyed observations can form a well-by-station sequence with masks. The network can emit a depth or scores on the same candidate states and edges. It needs an explicit rule for which neighboring stations it may see. | The measured first-party sequence comparator used BASE92 with a fixed 20-epoch schedule. Evaluating a network on exactly the new graph bundle requires matching its observation window, training partition and output keys. [Sequence comparison](MASTER_ITERATION.md) |

The public nodal harness now measures four consumers of one bundle. Every graph path, tree, forest and feed-forward neural prediction carries the same well and block keys. Each learned consumer is trained twice on the same folds, with the original 92 channels and with the additional 50 graph-derived channels. A focused test changes an observation beyond an edge and measures the resulting change in that earlier edge's weight. The study also replays errors against every original toe station. [Implementation, timings and measured controls](NODAL_HARNESS.md)

In all three views, a projected pixel and its originating XYZ sample share ancestry. A wider window changes the information available to a predictor. A longer optimizer run changes its computational budget. Holding these factors separately makes the two-speed comparison interpretable.

## Comparing how much work it takes

A training epoch is a pass through training examples. A solver pass moves evidence through a fixed graph. A Julia iteration updates a coordinate within one map. A lift creates a graph whose elements represent relations. Report each count in its own unit.

For a head-to-head comparison, freeze the raw observation set, station keys and well split. Compare the graph's fixed-weight path with its backward revision, a fitted conventional model and a fitted sequence model. Use the same target rows and report pooled TVT RMSE, per-well errors, training time, prediction latency, peak memory and share of paths left unresolved. Two controls separate new information from extra computation. Duplicating a view with the same ancestry tests double counting. Supplying a genuinely independent later observation tests whether the earlier alignment can improve. The resulting measurements determine whether fewer fitted epochs deliver the same accuracy at lower cost.
